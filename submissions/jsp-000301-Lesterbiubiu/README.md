# JSP-000301 — consecutive powerful numbers and perfect squares

**Problem bank entry:** [JSP-000301](https://github.com/TheJustinSunPrize/awards/blob/main/problems/catalog-0301-0400.md#JSP-000301)

> *If two consecutive positive integers are powerful, must at least one be a perfect square?*

## Scope

The problem bank records this question as **Solved (disproved)**, with the witness

```
12167 = 23 ^ 3            and            12168 = 2 ^ 3 * 3 ^ 2 * 13 ^ 2.
```

These two integers are consecutive, both are *powerful* (every prime divisor
occurs with exponent at least two), and neither is a perfect square.

This submission formalizes exactly that statement in Lean 4 and proves it
machine-checkably. It does not claim any new mathematics: the counterexample is
the one already recorded in the problem bank, and the content of the proof is
the arithmetic verification of that counterexample. **No novelty and no award
entitlement is claimed.**

`IsPowerful` is defined locally as

```lean
def IsPowerful (n : ℕ) : Prop := ∀ p : ℕ, p.Prime → p ∣ n → p * p ∣ n
```

## Proof sketch

* **Powerfulness.** `12167 = 23 ^ 3`, so any prime divisor of `12167` divides
  `23 ^ 3`; by `Nat.Prime.dvd_of_dvd_pow` it divides `23`, hence equals `23`, and
  `23 * 23 ∣ 23 ^ 3`. For `12168 = 2 ^ 3 * 3 ^ 2 * 13 ^ 2`, a prime divisor
  divides one of the three prime powers (by `Nat.Prime.dvd_mul` iterated), hence
  equals `2`, `3` or `13`, and each of `2 * 2`, `3 * 3`, `13 * 13` divides
  `12168`.
* **Not a square.** `110 * 110 = 12100 < n < 12321 = 111 * 111` for both
  `n = 12167` and `n = 12168`. If `n = k * k`, then `k ≤ 110` (otherwise
  `k * k ≥ 111 * 111 > n`) and `111 ≤ k` (otherwise `k * k ≤ 110 * 110 < n`),
  a contradiction.
* **Conclusion.** `12167` is a positive integer, both it and `12167 + 1` are
  powerful, and neither is a square, so the universally quantified claim in the
  problem statement fails.
