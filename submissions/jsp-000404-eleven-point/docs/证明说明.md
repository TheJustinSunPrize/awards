# Proof explanation

For eleven labels, introduce 55 real direction variables `theta(i,j)` for `i < j`, each in `[0,t)`. For each of the 165 triples `i < j < k`, put `a=theta(i,j)`, `b=theta(i,k)`, `c=theta(j,k)` and require either:

- `a <= b <= c`, `1 <= c-a`, `b-a <= t-1`, `c-b <= t-1`; or
- `c <= b <= a`, `1 <= a-c`, `a-b <= t-1`, `b-c <= t-1`.

The new certificate proves that these exact constraints contradict `t < 4`. It uses 6,205 Boolean atoms, 40,808 original clauses, 17,467 retained input clauses and 41,024 propositional derivation steps. Every retained input is proved from the actual model fields or checked real-arithmetic lemmas. `InputsValid` supplies these inputs; `LogicClosure` combines them into a contradiction; `ElevenModel` concludes `4 <= t`. Z3 and CaDiCaL discovered the certificate, while Lean checks the supplied proof terms.

For a genuine eleven-point configuration, let M be its maximum angle. Under the contrary assumption `M < 3*pi/4`, the attributed existing geometric reduction supplies a direction model with `t = pi/(pi-M) < 4`. The new model bound contradicts this. The maximum of the finite angle set is attained by a triple of pairwise distinct points, giving the public geometric theorem.

Cardinality monotonicity extends the angle guarantee to every configuration with at least eleven points. The attributed construction upper bound gives `alpha N <= 3*pi/4` for `N <= 16`, yielding equality throughout `11 <= N <= 16`.
