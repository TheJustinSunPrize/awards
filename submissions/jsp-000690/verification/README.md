# Verification evidence

The included [result.json](result.json) and
[build-and-axioms.log](build-and-axioms.log) were generated by
[scripts/verify.py](../scripts/verify.py) after cleaning this submission's
build cache and rebuilding its source with Lean 4.34.0 and bundled Std.
The executable path alone is normalized to `lake` in the public log so that
machine-local directories are not published. Build output and axiom output
are preserved.

The result records the compiler commit, UTC verification time, clean-build
flag, source hashes, and the transitive axiom dependencies of nine declarations.
All nine actual dependency lists are `[propext, Quot.sound]`. Both final
existence theorems are unconditional. There are no third-party Lean packages.

Reproduce from the submission directory:

```sh
python3 scripts/verify.py --clean
```

The script requires Python 3.9 or later and only its standard library. Lean
must be available through the pinned toolchain; `--lake /path/to/lake` is
supported. The script builds the project, runs `Audit.lean`, checks the exact
audited declaration list, rejects axioms outside Lean's standard logical
axioms, and hashes the source/configuration/script files. It supplies no
mathematical assumptions to Lean.

These are submitter-produced reproduction records. An additional AI-assisted
source review checked the finite-set representation, weak colouring,
coverage of all colouring functions, and full vertex-and-edge subgraph
criticality. It is not an independent human or prize-organizer certification.
Maintainers should reproduce the proof and assess the correspondence between
the formal definitions and the original statement.
