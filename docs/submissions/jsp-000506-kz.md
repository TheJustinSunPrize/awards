## Mathematical source and exact scope

Annika Heckel, *On a question of Erdős and Gimbel on the cochromatic number*,
Electronic Journal of Combinatorics 31(4) (2024), P4.72, Proposition 3:
[article](https://doi.org/10.37236/13346),
[author preprint](https://arxiv.org/abs/2408.13839).

For every natural graph order `n` and natural number `g`, the formal result is:

> If a uniform random simple labelled graph on `n` vertices has
> `chi - zeta <= g` with probability at least `999/1000`, then there is a
> natural number `k` such that `k <= chi <= k+g` has probability strictly
> greater than `9/10`.

The paper states this for an integer sequence with a strict `> 0.999`
premise. This implementation proves the pointwise version for natural `g`,
including equality at `0.999`. A negative integer gap bound cannot satisfy
the paper's premise since the gap is nonnegative. A separate Lean wrapper
for integer sequences is not part of the package.

The sole premise in `JSP000506.heckel_proposition3` is this probability bound.
Monotonicity of the chromatic number, complement invariance of the cochromatic
number, and `zeta <= chi` are proved in the same source. The auxiliary
`concentration_reduction` theorem gives the analogous statement on any finite
Boolean cube for an increasing natural-valued statistic and a smaller
complement-invariant statistic.

The proof uses a least 5-percent quantile, the Harris–Kleitman negative
correlation inequality for a lower event and an upper event, a complement
bijection, and a union bound. The mathematical argument is credited to Heckel;
the imported Harris–Kleitman formalization is credited to Mathlib's authors.
No new mathematical discovery is claimed.

## Definition review

- `Edge n` consists of pairs of vertices `i < j` in `Fin n`; each possible
  undirected edge is represented once. Its finite subsets represent all simple
  labelled graphs, including the empty vertex set when `n=0`.
- `mass A = |A| / 2^(card (Edge n))` uses rational arithmetic. Uniform counting
  over all edge subsets is the `G(n,1/2)` distribution. No random sampling or
  floating-point approximation is used.
- `Proper s k` is a vertex coloring into `Fin k` with distinct colors at each
  edge. `CoProper s k` additionally tags each color class as a clique or an
  independent set, requiring the corresponding adjacency relation for every
  same-colored vertex pair. Empty classes are permitted; minimization removes
  their effect on the number of classes.
- `chi` and `zeta` are the least possible numbers of colors. Existence is
  proved by coloring each vertex separately. Their required properties are
  proved from these definitions.
- Natural subtraction agrees with the intended gap because `zeta <= chi`
  is proved. The final statement includes all finite `n`.

This explanation is a submission-side statement review. An independently
signed equivalence review and a formal bridge to Mathlib's `SimpleGraph`
chromatic-number API are not supplied.
