## P4a 主等式（已验证，n=2..19 全匹配）

定义：u₁=1，u_{n+1}=⌊√2(u_n+1/2)⌋ = Nat.sqrt(2·u_n·(u_n+1))，d_n := u_{2n+1} − 2·u_{2n−1}。

**定理（精确位值）**：对 n ≥ 2，
```
d_n = Nat.sqrt (2^(2n−1)) mod 2
```
即 d_n 等于 √2 二进制展开的第 n 位（含整数位 1 作为第 1 位）。数值验证：n=1..19 全部一致。

## 关键闭式（二进制展开结构）

数值验证成立的核心恒等式：
```
u_{2n+1} = 2^n + Σ_{i=1}^{n} 2^{n−i} · b_i ，  b_i = d_i ∈ {0,1}
```
即 u_{2n+1} 的二进制表示是 `1 b_1 b_2 … b_n`（最高位 2^n 为 1，后随 n 个数字位）。
由此 d_n 正是 u_{2n+1} 的第 n 个低位数字位，且该位 = ⌊2^{n−1}√2⌋ mod 2 = Nat.sqrt(2^{2n−1}) mod 2。
