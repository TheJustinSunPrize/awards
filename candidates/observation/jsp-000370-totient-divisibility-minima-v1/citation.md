# Candidate observation

## English

This candidate observation is associated with [JSP-000370 — How large can the smallest integer whose totient is divisible by a prescribed positive integer be?](https://github.com/TheJustinSunPrize/awards/blob/main/problems/catalog-0301-0400.md#JSP-000370). It publishes `Statement.lean` and `Proof.lean` for a complete, machine-checked Lean proof of two explicit instances concerning the least positive integer `n` with `k ∣ φ(n)`, where `φ` is Mathlib's `Nat.totient`. For `k = 6` the minimum is exactly `7 = 6 + 1` (`6 ∣ φ(7)`, and the totients `φ(1), …, φ(6) = 1, 1, 2, 2, 4, 2` are never divisible by `6`); for `k = 13` the minimum is exactly `53 = 4 · 13 + 1` (`13 ∣ φ(53)`, and no `1 ≤ m ≤ 52` satisfies `13 ∣ φ(m)`). Together the two instances show that the ratio of the minimum to `k` is not a fixed constant close to `1`: it equals `7 / 6` for `k = 6` but `53 / 13 > 4` for `k = 13`. **Scope: this observation verifies only the two explicit instances `k = 6` and `k = 13` (in each case the witness works and every smaller positive integer fails). How large the minimum can be for a general prescribed `k` — the actual catalog question — is not addressed, the catalogued problem is not resolved, and no award claim is made.** The catalog entry JSP-000370 remains Open.
