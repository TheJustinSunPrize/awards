# Candidate observation

## English

This candidate observation is associated with [JSP-000903 — How many triangles of the same area can a finite planar point set determine?](https://github.com/TheJustinSunPrize/awards/blob/main/problems/catalog-0901-1000.md#JSP-000903). It publishes `Statement.lean` and `Proof.lean` for a complete, machine-checked Lean formalization of the `n = 4` attainment instance of the catalog question: there exists a set of four points in the plane — the vertices of the unit square, `{(0,0), (1,0), (1,1), (0,1)}` — such that every triangle formed by three pairwise distinct points of the set has the same ordinary area `1/2` (absolute doubled signed area `1`). Since a four-point set determines at most `C(4,3) = 4` triangles, this configuration attains that counting upper bound with all four triangles of equal area. The main theorem proved is `jsp000903 : ∃ s : Finset (ℚ × ℚ), s.card = 4 ∧ ∀ a ∈ s, ∀ b ∈ s, ∀ c ∈ s, a ≠ b → b ≠ c → a ≠ c → |area2 a b c| = 1`, where `area2 a b c` is the doubled signed area of the triangle `abc`; the companion theorem `jsp000903_four_triangles` lists the four triangles explicitly.

**Scope boundary:** this observation records only the `n = 4` attainment instance (existence of a configuration reaching the trivial `C(4,3)` counting bound with all triangles of equal area; the witness is modeled in `ℚ² ⊂ ℝ²`, in which it is exact since the doubled area is an integer-coefficient polynomial of the coordinates). It does not address the general extremal question (the maximum number of equal-area triangles over all `n`-point sets, for arbitrary `n`), does not resolve the catalogued open problem, which remains Open, and makes no award claim.
