# Candidate observation

## English

This preliminary observation is associated with [JSP-000194 — How many ordinary lines, each containing exactly two of the points, must a finite noncollinear planar point set determine?](https://github.com/TheJustinSunPrize/awards/blob/main/problems/catalog-0101-0200.md#JSP-000194). It publishes `Statement.lean` and `Proof.lean` for the finite three-point ordinary-line corollary. This is an `n = 3` specialization, not a formalization or solution of the full quantitative catalog question; the public source is [Motzkin's paper](https://doi.org/10.1090/S0002-9947-1951-0041447-9).

A local Lean compilation was run with Lean 4.33.1 and the pinned Mathlib revision. That compiler result is only a reproducibility check; it is not independent verification of statement faithfulness or official JSP verification.

The candidate remains under verification. No award decision, recipient identity, solver or formalizer credit, payment, or official verification is asserted.
