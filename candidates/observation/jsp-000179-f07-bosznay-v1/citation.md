# Candidate observation

## English

This preliminary observation is associated with [JSP-000179 — How large can a subset of an integer interval be if no element is the average of some other elements?](https://github.com/TheJustinSunPrize/awards/blob/main/problems/catalog-0101-0200.md#JSP-000179). It publishes `Statement.lean` and `Proof.lean` for the finite Bosznay non-averaging construction described in [the public source](https://arxiv.org/abs/2410.14624). This is a construction component, not a formalization or solution of the full asymptotic catalog question.

A local Lean compilation was run with Lean 4.33.1 and the pinned Mathlib revision. That compiler result is only a reproducibility check; it is not independent verification of statement faithfulness or official JSP verification.

The candidate remains under verification. No award decision, recipient identity, solver or formalizer credit, payment, or official verification is asserted.
