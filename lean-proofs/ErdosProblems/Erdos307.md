# Erdős Problem 307

This is a formalized proof of [Erdős Problem 307](https://www.erdosproblems.com/forum/thread/307).

It is available for these Mathlib (and Lean) versions:

* [Mathlib/Lean v4.33.0](../src/latest/ErdosProblems/Erdos307.lean) (latest stable release).

Erdős Problem 307: Can three consecutive integers have strictly decreasing largest prime factors?

Answer: Yes. For example, n = 13 gives P(13) = 13 > P(14) = 7 > P(15) = 5.

Informal authors:
- P. Erdős and C. Pomerance (original proof, 1978)

Formal author:
- OpenAI Codex
