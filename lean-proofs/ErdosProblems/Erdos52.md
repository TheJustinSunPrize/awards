# Erdős Problem 52

This is a formalized proof of [Erdős Problem 52](https://www.erdosproblems.com/forum/thread/52).

It is available for these Mathlib (and Lean) versions:

* [Mathlib/Lean v4.33.0](../src/latest/ErdosProblems/Erdos52.lean) (latest stable release).

Erdős Problem 52: Are there infinitely many consecutive integers with equal divisor counts?

Answer: Yes. The proof exhibits many explicit solutions including n = 2 (d(2)=d(3)=2), n = 14 (d(14)=d(15)=4), n = 21 (d(21)=d(22)=4), and many more.

Informal authors:
- P. Erdős and C. Pomerance (original proof, 1952)

Formal author:
- OpenAI Codex

The detailed mathematical proof and Leanization plan are in tex/52.tex.
